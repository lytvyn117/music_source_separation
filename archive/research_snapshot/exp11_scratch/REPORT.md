## Loss и стерео

`x` обозначает смесь, `v` — вокальный таргет, `ŷ` — оценку вокала, `e = ŷ − v`. `Z_x, Z_v, Z_ŷ` — STFT с теми же FFT/hop/Hann и **constant** padding в loss. Для каждого примера `s = sqrt(max(mean_C,F,K |Z_x|², 1e−8))`, `r = sqrt(max(mean_C,T x², 1e−8))`. `K` — время STFT, `F` — частота, `T` — отсчёты, `B` — batch. Ниже строки относятся к `exp10_scratch/exp09_core/loss_candidates.py`.

| Термин | Определение и редукция | Вес | Медиана Exp10 / последние 1 000 шагов |
| --- | --- | ---: | ---: |
| `complex_mse`, строка 49 | `mean_B,C,F,K(|Z_ŷ − Z_v|² / s²)`. Ошибка модуля комплексной разности, включает фазу. Комплексная ошибка инструментала при комплементарной реконструкции та же с обратным знаком. | 1 | 0,03909 / 0,02974 |
| `logmag_l1`, строка 50 | При `f(Z)=log1p(|Z|/s)` полусумма `mean_B,C,F,K(abs(f(A)−f(B)))` по парам `(Z_ŷ,Z_v)` и `(Z_x−Z_ŷ,Z_x−Z_v)`. Оба стема имеют равный вес внутри члена. | 0,5 | 0,02266 / 0,01960 |
| `wave_l1`, строка 51 | `mean_B,C,T(abs(e)/r)`. Инструментальная waveform-ошибка комплементарна. | 2 | 0,12110 / 0,10440 |
| `side_l1`, строка 52 | `mean_B,T(abs(e_L−e_R)/(2r))`. Side инструментальной ошибки комплементарен. Знаменатель общий по L/R смеси. | 0,25 | 0,05041 / 0,04416 |
| `leakage`, строки 13–23 и 46–53 | Для каждой полной секунды `j` `p_j=Σ_C,Tj[(v−ŷ)v]/max(Σ_C,Tj v²,1e−8)`. Активна при `Σv² > 0,005²·C·44100`. Штраф `Σ_active(max(abs(p_j)−0,05,0)²)/max(N_active,1)` по активным секундам всего батча. Проекция чувствительна к знаку ошибки, симметричный штраф действует на избыток обоих знаков. | 0,25 | 0,03403 / 0,01697 |

Вход модели проходит `asinh` без нормализации на RMS, поэтому эта инвариантность формул не переносится на поведение модели при масштабировании входа. Медиана полной loss равна 0,31849 по всем шагам. - Место **12 GiB** в дополнение к существующему ZIP и кэшу для пилота, **15 GiB** для потенциального полного прогона. Верхняя граница временных train refs — 9,32 GiB. Зрелый checkpoint около 179 MiB, семь номерных состояний до шага 6 000, плюс алиасы и атомарная публикация.

Валидация на 1 000, 2 000, 3 000, 4 000, 5 000 и 6 000 использует прежний FP32 positive-Hann overlap-add (четыре секунды, hop две), SDR как медиану активных секунд при −45 дБFS и Side SDR всего трека при пороге −50 дБFS. Отчёт оценивает Raw с Raw и EMA с EMA на шаге 6 000. Он включает по-песенные, по-артистовые и artist-macro метрики, парные дельты, finite checks и уровни фактически использованных миксов. Допуски 0,10 дБ для обоих SDR, 0,15 дБ для обоих Side SDR и один процентный пункт для bleed. Максимальный остаток проверяется относительно соответствующей ветки Exp10. Для предложения полного запуска нужен заметный положительный сигнал, распределённый по семи группам, при численной стабильности. Одна пара seed и семь групп ограничивают статистическую мощность. Допуски сами по себе достаточны только для проверки отсутствия заданной деградации.
