# Exp08 subband separator implementation plan

**Status** — Awaiting implementation approval.

**Goal** — Implement and verify the approved Exp08 custom stereo separator in an isolated experiment namespace.

**Architecture** — Three frequency bands, two frequency-only compression stages, temporal residual stack, and complementary bounded complex masks. The train-only probe selected normalized complex MSE with explicit auxiliary terms and no redundant source weights.

**Stack** — Existing PyTorch 2.7.1+cu128 environment, CUDA BF16 and FP32, SoundFile, and pytest.

**Spec** — [Exp08 design](../specs/2026-11-10-exp08-subband.md)

## 1. Preserve and freeze inputs

- [ ] Before any checkout or new production source, inventory tracked edits and untracked sources. Capture hashes of the current source tree and Exp01–Exp07 artifacts. Use the verified working source as the basis of isolation because HEAD alone omits needed files. Keep existing paths and bytes intact.
- [ ] Create only Exp08 production paths under src/experiments/exp08_subband and tests/exp08. Reserve separate run IDs under models/experiments/exp08_subband, outputs/logs/exp08_subband, and reports/exp08_subband.
- [ ] Write failing isolation tests in tests/exp08/test_data.py for altered track lists, official test paths, duplicate IDs, and an attempt to reuse an existing run directory.
- [ ] Implement manifest checks in src/experiments/exp08_subband/data.py using src/data/splits.py and src/data/dataset_v2.py as references. Store ordered 85/15 IDs, WAV and source fingerprints, clip and excerpt manifests, and the Exp04 checkpoint SHA-256. Make augmentations reproducible by seed, epoch, and sample index, including both source IDs and joint channel swaps. Run the isolation tests.

## 2. Implement the model and waveform adapter

- [ ] In tests/exp08/test_model.py write failing tests for every tensor stage at B=2/T=862 and B=1/T=517, the exact 653,650-parameter count, temporal tap support, edge-bin reality, L/R ordering, band seam alignment, and complementary bounded outputs. Include zero input, unequal channels, near cancellation, and impulses around both band cuts.
- [ ] Implement SubbandSeparator in src/experiments/exp08_subband/model.py. Provide a complex-STFT entry point producing the vocal and instrumental spectra and a waveform entry point returning [B,2,2,L]. Reuse src/audio/stft.py and implement the spec's band crops and FP32 head.
- [ ] In tests/exp08/test_inference.py write failing exact-length and overlap-add tests for shorter-than-window inputs and irregular tails. Implement src/experiments/exp08_subband/inference.py with equal overlap-add weights for both stems. Verify spectral and waveform additivity and stereo channel orientation.

## 3. Implement the frozen objective

- [ ] Port the feasibility source-weight test to tests/exp08/test_loss.py. Add failing tests for projected targets, scalar normalization per clip, the factor-of-two convention for complex MSE, zero-error and silent gradients, distinct nonlinear magnitude terms, and positive, negative, inactive and no-active leakage cases. Check that vocal-specific projection gradients differ from the shared MSE gradient. Run a small FP64 finite-difference or autograd gradcheck away from nondifferentiable boundaries.
- [ ] Implement src/experiments/exp08_subband/loss.py with projected targets and the exact coefficients in the spec. Return the total and named unweighted terms. Reduce common errors once. Verify the regression fails under a deliberately incorrect weighted sum or normalization and passes with the final formula.

## 4. Implement the trainer and checkpoints

- [ ] Write failing tests in tests/exp08/test_training.py and tests/exp08/test_checkpointing.py for accumulated gradient scaling, selection ties/min_delta/patience, finite and amplification stops before update, interrupted checkpoint publication, mismatched config/split, and continuous versus resumed execution.
- [ ] Implement src/experiments/exp08_subband/train.py and checkpointing.py. Reuse selection rules from src/training/experiment_selection.py. Publish immutable checkpoint payloads via an atomic commit record that identifies both latest and best. On resume load the last committed epoch, require matching fingerprints and reject incomplete or corrupt payloads. Capture RNG, sampler, schedule, optimizer, history, and selection state. Keep epoch zero and ten-epoch snapshots.
- [ ] Run CPU regression tests and an isolated deterministic CUDA resume test. Verify FP32 and BF16 gradients in all branches and overfit a small fixed train-only stereo batch.

## 5. Measure production readiness on training data

- [ ] In a new smoke run directory, measure 100 real-data optimizer updates after eight untimed profiling updates, at the specified peak LR with production-mode data loading and guards. Record allocated and reserved VRAM, headroom, synchronized throughput, clipping, loss and per-branch gradients.
- [ ] Grade the measured clipping rate and replay the bounded oracle against the frozen panel. Stop for review if a resource, numeric, continuation, or gradient gate fails. Retain all smoke evidence separately. Full training is a separate approval.
- [ ] Rerun protected-artifact fingerprints and Exp08 tests. Deliver a readiness report and reproducible commands for review.

## 6. Evaluate and decide after an approved full run

- [ ] In tests/exp08/test_evaluation.py cover the fixed track join, NaNs for inactive frames, blind export alignment and amplitude preservation, and GO/NO-GO boundary values.
- [ ] Implement src/experiments/exp08_subband/evaluate.py using the existing metric and paired export utilities. Score the frozen Exp04 baseline and exactly one selected Exp08 checkpoint. Run the paired bootstrap with a recorded seed and 10,000 track resamples. Publish complete reports and the gate table under the run's report directory. Retain Exp04 unless every criterion passes.
